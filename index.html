Formula Reference Sheet
Ch. 1–2 · Foundations & Equations
Order of Operations (PEMDAS)
P → E → MD → AS
Parentheses, Exponents, Multiply/Divide, Add/Subtract
Distributive Property
a(b + c) = ab + ac
Simple Interest
I = Prt
P = principal, r = rate, t = time
Absolute Value
|x| = x if x ≥ 0
|x| = −x if x < 0
Ch. 5 · Linear Functions
Slope
m = (y₂ − y₁) / (x₂ − x₁)
Slope-Intercept Form
y = mx + b
m = slope, b = y-intercept
Point-Slope Form
y − y₁ = m(x − x₁)
Standard Form
Ax + By = C
A, B, C are real numbers; A & B not both 0
Distance Formula
d = √((x₂−x₁)² + (y₂−y₁)²)
Midpoint Formula
M = ((x₁+x₂)/2, (y₁+y₂)/2)
Direct Variation
y = kx
k = constant of variation
Ch. 7 · Exponents & Polynomials
Zero Exponent
x⁰ = 1
x ≠ 0
Negative Exponent
x⁻ⁿ = 1/xⁿ
x ≠ 0
Product of Powers
xᵃ · xᵇ = xᵃ⁺ᵇ
Quotient of Powers
xᵃ / xᵇ = xᵃ⁻ᵇ
x ≠ 0
Power of a Power
(xᵃ)ᵇ = xᵃᵇ
Power of a Product
(xy)ⁿ = xⁿyⁿ
Rational Exponent
x^(1/n) = ⁿ√x
Scientific Notation
a × 10ⁿ
1 ≤ a < 10, n is an integer
Ch. 8 · Factoring
Factoring by GCF
ab + ac = a(b + c)
Difference of Squares
a² − b² = (a+b)(a−b)
Perfect Square Trinomial
a² + 2ab + b² = (a+b)²
a² − 2ab + b² = (a−b)²
Trinomial (a=1)
x² + bx + c = (x+p)(x+q)
where p + q = b and p · q = c
Ch. 9 · Quadratic Functions & Equations
Standard Form (Quadratic)
y = ax² + bx + c
a ≠ 0
Axis of Symmetry
x = −b / (2a)
Vertex
(−b/2a, f(−b/2a))
Quadratic Formula
x = (−b ± √(b²−4ac)) / 2a
Discriminant
b² − 4ac
>0: two real solutions; =0: one; <0: none
Completing the Square
x² + bx + (b/2)² = (x + b/2)²
Constant Acceleration
d = vt + ½at²
d = distance, v = starting velocity, a = acceleration
Ch. 10 · Data Analysis & Probability
Theoretical Probability
P(E) = favorable outcomes / total outcomes
Experimental Probability
P(E) = times event occurs / total trials
Complement
P(not E) = 1 − P(E)
Independent Events
P(A and B) = P(A) · P(B)
Permutations
nPr = n! / (n−r)!
Combinations
nCr = n! / (r!(n−r)!)
Ch. 11 · Exponential & Radical Functions
Geometric Sequence (nth term)
aₙ = aₙ₋₁ · r
r = common ratio
Geometric Sequence (explicit)
aₙ = a₁ · r��⁻¹
Exponential Growth
y = a(1 + r)ᵗ
a = initial amount, r = growth rate, t = time
Exponential Decay
y = a(1 − r)ᵗ
a = initial amount, r = decay rate, t = time
Product Property of Radicals
√(ab) = √a · √b
Quotient Property of Radicals
√(a/b) = √a / √b
b ≠ 0
Pythagorean Theorem
a² + b² = c²
c = hypotenuse
Ch. 12 · Rational Functions & Equations
Inverse Variation
y = k/x or xy = k
k = constant of variation, x ≠ 0
Rational Function (general)
f(x) = p(x) / q(x)
q(x) ≠ 0
Multiplying Rational Expressions
(a/b) · (c/d) = ac/bd
Dividing Rational Expressions
(a/b) ÷ (c/d) = (a/b) · (d/c)
